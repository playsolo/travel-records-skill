## 使用顺序

1. 先用合成样例录制结果演示；真实安装、授权及邮件读取单独实录。没有录到的操作不拼成成功过程。
2. 小范围邀请 10–20 位经常旅行或出差的用户。首轮核对一段已知行程，再扩大至年度邮件。
3. 私下确认测试环境和可用安装方式。当前私有市场依赖本机注册，不能把维护者本机安装链接当作通用下载链接。
4. 发布招募帖时，在原帖评论接收意向；另行安排私密沟通方式。公开回复只收系统、客户端和使用场景。
5. 根据失败反馈修改安装流程和介绍；正式上架前再替换安装入口及支持范围。

这些是内容素材，未创建公开网站、发布帖子或提交插件目录。现有 skill 的安装方式见 [中文 README](../README_ZH.md)，不等同于插件已公开上架。

## 第一轮记录什么

按用户自愿反馈汇总，不加入邮箱内容或自动埋点。安装尝试、首次任务和核对样本分开计数，未完成或未反馈单列。

| 指标 | 计算口径 |
| --- | --- |
| 安装成功率 | 已确认启用插件并能运行首次设置的人数 / 实际尝试安装人数 |
| 首份清单交付率 | 在首次尝试中拿到可打开清单的人数 / 实际发起提取人数；另记有无待处理项 |
| 已知记录找回率 | 盲测中正确找回的目标记录数 / 用户事先独立整理的目标记录数 |
| 字段正确率 | 与原件一致的已抽查字段数 / 已抽查字段数；日期、状态、金额、币种分别报告 |
| 首次交付耗时 | 从首次设置开始到打开首份清单的实际时间；失败和中断单列 |

目标记录若事先提示给 Agent，应标为定向核对，不能作为自主发现的找回率。通过格式校验或处理完已发现材料也不能代替完整召回验证。详细方法见 [Gmail 验收流程](../docs/gmail-acceptance.zh-CN.md)。

## English usage notes

Record the synthetic result demo first. Capture installation, authorization and real-mail reading separately; only show steps that actually succeeded. Invite 10–20 travelers to review a known trip before attempting a year of mail. Arrange private installation individually: the maintainer's registered local marketplace link is not a universal installer.

When publishing an invitation, collect interest in that post's replies and arrange private follow-up separately. Keep public replies to platform, client and use case. These files do not publish a website, post or directory listing. The [English README](../README.md) describes the existing standalone skill installation.

With voluntary, content-free feedback, track installation success, first-list delivery, independently established target-record recall, checked-field accuracy and time to first delivery. Use actual attempts as denominators and report unfinished cases separately. A directed lookup is not a blind discovery test; completed candidate processing is not proof of complete mailbox recall.
